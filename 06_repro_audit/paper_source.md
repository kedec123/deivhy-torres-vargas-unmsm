# Paper Selected for the Reproducibility Audit

**Kukkar, A., Loibor, J. M., Cifci, M. A., Barman, M. P., Hussain, S., Gaftandzhieva, S., and Doneva, R. (2026). _Improved prediction of childhood anemia using hybrid ensemble learning and dual-level explainability_. Journal of Public Health Research, 15(2), 22799036261462908. https://doi.org/10.1177/22799036261462908**

The audit used the open full text in [PubMed Central](https://pmc.ncbi.nlm.nih.gov/articles/PMC13305737/) on 31 July 2026. It was chosen because it is directly about machine-learning prediction of childhood anemia using a DHS dataset, making it relevant to the technical component of this repository without being treated as evidence about Peru.

This is a document audit, not an attempted replication. The paper reports TDHS 2022 data, a stacked TabNet/XGBoost/MLP approach, stratified splitting, class weighting, and multiple optimisation methods. It also states that code was available on request and that a public release was planned. The audit records what is stated in the paper and does not speculate about author intent or the quality of unobserved code.
