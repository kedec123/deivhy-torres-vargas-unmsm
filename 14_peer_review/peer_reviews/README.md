# Peer Reviews

This folder is intentionally empty of completed reviews. Before final submission, two real reviewers should independently use the provided forms, identify themselves as permitted by the course, and return their actual feedback. Do not create a fictional review to fill this requirement.

Use `review_form_1.md` for the research argument and `review_form_2.md` for reproducibility, ethics, and integrity. After receiving both forms, create `03_protocol/protocol_v2.0.md` from its response table: quote or accurately paraphrase each substantive comment, state the decision, describe the action, and point to the revised text.
