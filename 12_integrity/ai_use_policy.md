# AI Use Policy for This Project

## Green: permitted assistance

AI tools may be used for spelling, grammar, clarity suggestions, code explanation, test ideas, formatting, and locating sources that are then checked against the original record. Humanizer is used only as an editorial pass to reduce repetitive or mechanical wording. It must not change data values, citations, quotations, results, personal reflections, or claims of what the author did.

## Amber: allowed only with author review and disclosure

Drafting a structure, suggesting alternative wording, generating code that is inspected and tested, or summarising a source can be useful with careful author review. The author must verify every factual statement, execute or inspect every technical artefact, revise text to reflect their own understanding, and disclose meaningful assistance if the course requires it.

## Red: prohibited use

AI must not fabricate data, citations, screening decisions, peer feedback, reflections, research experiences, or experimental results. It must not conceal authorship, imitate a reviewer, bypass course rules, write a personal reflection on the author's behalf, or be used to make clinical or administrative decisions from the model.

## Project disclosure

This repository used computational assistance for initial drafting, code scaffolding, and editorial clarity checks. The author remains responsible for source verification, methodological decisions, executed results, final wording, and any personal academic statements. Peer reviews and reflective entries remain templates until completed by real people.

## Operating rules

1. Check every citation against the original article, official data record, or publisher notice before retaining it.
2. Run or inspect code before describing its output as a result.
3. Keep the repository record honest: do not backdate work, create a fictional reviewer, or replace an earlier version without a commit.
4. Use Humanizer only for editorial clarity. It must not alter numbers, links, quotations, data definitions, citations, or personal claims.
5. When a use falls near the boundary between editing and substantive drafting, treat it as Amber, seek the course-required approval, and record it rather than choosing the more convenient label.

## Personal review required before submission

The author must read the final protocol, tables, code comments, and disclosure record in full. The author must also complete the peer-review and reflective-writing artefacts personally. These checks cannot be delegated to an AI tool, because they are evidence of understanding and academic judgement.

## Prompt-log location

`ai_prompt_log/README.md` provides a blank record format for any assistance that requires disclosure. The repository intentionally does not contain fabricated retrospective entries. The author should add a dated record only when it accurately describes a real interaction and any required approval.
