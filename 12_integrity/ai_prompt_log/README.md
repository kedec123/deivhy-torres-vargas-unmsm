# AI Assistance Log Template

Use one dated entry per meaningful assistance event when the course policy or advisor requires a record. Do not create retrospective entries from memory if the details cannot be stated accurately.

```text
Date:
Tool and version:
Category under the project policy: Green / Amber / Red check:
Task:
Material provided by the author:
What the tool returned:
What the author independently checked or changed:
Approval record, if Amber:
Where the resulting change appears in the repository:
```

This template is a governance record, not a substitute for author responsibility. No prompt content, credential, personal information, unpublished sensitive data, or private review should be committed to Git.
