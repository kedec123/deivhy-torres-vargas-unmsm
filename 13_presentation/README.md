# Presentation

Open `index.html` in a browser. The redesigned nine-slide deck presents the
primary survey analysis before the exploratory classifier, includes a static
QR code to the public repository, and is self-contained apart from optional
web fonts.

Controls: arrow keys or Space to navigate; `O` for slide overview; `S` for
speaker prompts; and `F` for fullscreen. The QR code is stored locally as
`assets/repository-qr.svg`, so it remains available when the file is opened
from GitHub Pages or copied with its presentation folder.
