# Reflective Log Template

This file is a template, not a completed reflection. The author should write the entries in their own words after each course unit.

## Unit 1: Paradigm and method

What decision did I make? What evidence or concern changed my thinking? What would I defend differently now?

## Unit 2: Literature and protocol

What did the search process reveal about the question, sources, or the limits of the planned study?

## Unit 3: Data and reproducibility

What did I learn while building or running the ENDES pipeline? Which reproducibility problem was harder than expected?

## Unit 4: Ethics, bias, and integrity

How did the ethics, model-card, fairness, and retraction exercises affect the way I interpret technical results?

## Final synthesis

How has the project changed from the first topic statement to the final repository? Which decisions remain provisional, and why?
